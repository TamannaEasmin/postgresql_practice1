# Week 2 PostgreSQL Practice

This project demonstrates my SQL skills using PostgreSQL.

## Features
- Database schema with 3 tables (users, products, orders)
- Foreign key relationships
- Real-world queries for data analysis


## How to Run
1. Create database: `CREATE DATABASE shop_project;`
2. Run schema: `psql -d shop_project -f schema.sql`
3. Insert data: `psql -d shop_project -f seed.sql`
4. Run queries: `psql -d shop_project -f queries.sql`
